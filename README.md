## 🕹️ Controls

| Action          | Key         |
|-----------------|-------------|
| Move Left       | `A` or ⬅️   |
| Move Right      | `D` or ➡️   |
| Jump            | `Space`     |
| Dash            | `Shift`     |
| Shield          | `Q`         |
| Normal Attack   | `J`         |
| Skill 1         | `K`         |
| Skill 2         | `L`         |
